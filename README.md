# solmara-earned-pride

One line for make.fun's "One Line of Earned Pride" bounty: a mother frames her nursing certificate above the sink where she used to study. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
